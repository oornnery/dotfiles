# Project instruction templates

Copy only files needed by project; these templates are not auto-loaded from this
directory.

- `AGENTS.base.md` → project-root `AGENTS.md`.
- Merge `AGENTS.python.md`, `AGENTS.tsjs.md`, or `AGENTS.harness.md` into project
  guide when stack applies.
- `.spec/` tracks milestone state, checks, and handoff for nontrivial work.
- `.mem/` is optional durable project memory. Cavemem remains session memory.

Replace `{{placeholders}}`, delete unused sections, and keep project guide short.
