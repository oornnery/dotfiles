# Accessibility and interaction

- Native element before ARIA recreation.
- Every input has programmatic label and useful error association.
- Keyboard order follows visual/logical order.
- Focus is visible, intentional, and restored after dialogs/navigation when needed.
- Dialogs trap focus, close predictably, and return focus.
- Color is not sole status signal.
- Respect reduced motion and zoom/reflow.
- Test loading, empty, error, success, disabled, hover, focus, active, overflow, and
  long/localized content.
