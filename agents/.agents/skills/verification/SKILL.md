# Verification

Choose checks by changed surface and failure risk, not ritual.

1. Reproduction/focused test.
2. Relevant suite.
3. Format/lint.
4. Type/LSP.
5. Build/package.
6. Migration/browser/integration/security as affected.

Record exact command, exit result, and relevant output. `PASS` requires requirements and
checks, not absence of obvious error. `BLOCKED` names missing evidence. Never claim
unrun checks or weaken checks to get green.
