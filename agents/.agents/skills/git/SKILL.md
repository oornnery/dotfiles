# Git

Inspect `status`, branch, diff, and recent log before mutation. Preserve unrelated work.
Stage explicit paths. Commit one coherent change with repository convention and no AI
trailers. Never force-push, reset hard, clean, restore, rewrite shared history, or
delete branches without explicit approval and recovery plan.

Use worktrees for independent concurrent edits. During conflicts, understand both sides
and rerun checks. Prefer `reflog`, backup branch, or stash for recovery.
