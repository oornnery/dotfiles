# zk

Notes as Markdown files that link to each other, searched with fzf.

Project: <https://github.com/zk-org/zk>

## Start

- `zk new --title "An idea"`
- `zk edit --interactive`: pick with fzf
- `zk list`
- `zk list --link-to file.md`: what links to it

## Notes

- Notes in `~/notes`; `dots install tui-notes` creates it.

From its documentation.
