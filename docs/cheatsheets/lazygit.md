# lazygit

Git in panels: status, files, branches, commits, stash.

Project: <https://github.com/jesseduffield/lazygit>

## Start

- `lg` or `lazygit` in a repo
- `Alt g` in the shell and in Zellij

## Keys

| Key | Action |
| --- | ------ |
| `1`-`5` | Panels: status, files, branches, commits, stash |
| `space` | Stage or unstage the file |
| `a` | Stage all |
| `c` | Commit |
| `P` | Push |
| `p` | Pull |
| `Enter` | Open: the diff of a file, the commits of a branch |
| `n` | New branch (in branches) |
| `/` | Filter the panel |
| `?` | Every key of the panel |
| `q` | Quit |

## Notes

- Its config is `home/lazygit`; the colors are the terminal ones, so it follows `dots theme`.
