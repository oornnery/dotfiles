# lazyssh

SSH hosts: pick, add, connect, forward ports. Reads and writes `~/.ssh/config`.

Project: <https://github.com/Adembc/lazyssh>

## Start

- `lazyssh`

## Keys

| Key | Action |
| --- | ------ |
| `Enter` | Connect |
| `a` | Add a host |
| `e` | Edit |
| `d` | Delete |
| `c` | Copy the ssh command |
| `g` | Ping |
| `f` `x` | Start, stop a port forward |
| `p` | Pin |
| `/` | Search |
| `q` | Quit |

Keys read from its own help screen.
