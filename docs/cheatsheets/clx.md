# circumflex

Hacker News: stories, comments as a tree, and the article in reader mode.

Project: <https://github.com/bensadeh/circumflex>

## Start

- `clx`

## Keys

| Key | Action |
| --- | ------ |
| `Enter` | Comments |
| `Space` | The article, in reader mode |
| `o` | The article in the browser |
| `c` | The comments in the browser |
| `Tab` | Next category |
| `/` | Search |
| `f` `x` | Add, remove a favorite |
| `r` | Refresh |
| `i` | Every key |
| `q` | Quit |

## Notes

- Links open in the Windows browser (`BROWSER`).
