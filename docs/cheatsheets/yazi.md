# Yazi

File manager with previews: text, images, PDFs, videos.

Project: <https://github.com/sxyazi/yazi>

## Start

- `y`: the shell follows it to the folder you leave in
- `Alt e` in the shell and in Zellij

## Keys

| Key | Action |
| --- | ------ |
| `h` `j` `k` `l` | Move; `l` or `Enter` opens |
| `Space` | Select |
| `a` | Create; ending in `/`, a folder |
| `r` | Rename |
| `y` `x` `p` | Copy, cut, paste |
| `d` | Move to the trash |
| `.` | Hidden files |
| `s` `S` | Search names (fd), contents (rg) |
| `z` `Z` | Jump with fzf, zoxide |
| `W` `T` | A shell here: pane, tab (in Zellij) |
| `~` | Every key |
| `q` | Quit |

## Notes

- Opens text in Helix. Icons and colors follow `dots theme`; images show as sixel in Windows Terminal.

More in `dots help keys`.
