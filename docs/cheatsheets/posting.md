# posting

HTTP requests, like Postman, saved as YAML files you can keep in git.

Project: <https://github.com/darrenburns/posting>

## Start

- `posting`: requests saved in the folder it runs in
- `posting --collection path`

## Keys

| Key | Action |
| --- | ------ |
| `Ctrl l` | The URL; a curl command pasted there fills the request |
| `Ctrl t` | Method |
| `Ctrl j` | Send |
| `Ctrl s` | Save |
| `Ctrl n` | New request |
| `Ctrl P` | Search requests |
| `Ctrl o` | Jump to any part |
| `Ctrl p` | Every command |
| `Ctrl h` | Show or hide the collection |
| `F1` | Help |
| `Ctrl c` | Quit |

## Notes

- Its theme is the dots theme (`POSTING_THEME`, set by the shell).

Keys read from its own help screen.
