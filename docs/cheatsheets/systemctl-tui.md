# systemctl-tui

systemd units: their state, logs, and start, stop, restart.

Project: <https://github.com/rgwood/systemctl-tui>

## Start

- `systemctl-tui`

## Keys

| Key | Action |
| --- | ------ |
| `j` `k` | Move |
| `/` `Ctrl f` | Search |
| `Enter` `Space` | The commands of a unit: start, stop, restart... |
| `f` `F2` | Filter units |
| `Ctrl p` | Every command |
| `Ctrl r` | Reverse the logs |
| `Ctrl l` | Show or hide the logger |
| `PageUp` `PageDown` | Scroll the logs |
| `?` `F1` | Help |
| `Ctrl q` | Quit |

Keys read from its own help screen.
