# presenterm

Slides from a Markdown file.

Project: <https://github.com/mfontanini/presenterm>

## Start

- `presenterm docs/slides/dots.md`
- `presenterm -p file.md`: presentation mode

## Keys

| Key | Action |
| --- | ------ |
| `Right` `Left` | Next, previous slide |

## Notes

- Slides end at `<!-- end_slide -->`; `<!-- pause -->` shows the rest on the next key.
- Theme `terminal-dark`: the terminal colors.

From its documentation.
