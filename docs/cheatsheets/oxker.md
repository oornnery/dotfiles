# oxker

Docker containers: state, logs, and start, stop, restart, exec.

Project: <https://github.com/mrjackwills/oxker>

## Start

- `oxker`

## Keys

| Key | Action |
| --- | ------ |
| `Tab` `Shift Tab` | Next, previous panel |
| `j` `k` | Move |
| `Enter` | A command for the container |
| `e` | Shell in the container |
| `i` | Inspect |
| `/` `F1` | Filter |
| `#` | Search the logs |
| `s` | Save the logs |
| `1`-`9` `0` | Sort by column, stop sorting |
| `m` | Mouse capture, off to select text |
| `h` | Help |
| `q` | Quit |

## Notes

- Config: `~/.config/oxker/config.toml`.

Keys read from its own help screen.
