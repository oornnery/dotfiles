# trippy

traceroute and ping together: every hop, its loss and its times, with graphs.

Project: <https://github.com/fujiapple852/trippy>

## Start

- `trip 1.1.1.1`
- `trip google.com`

## Keys

| Key | Action |
| --- | ------ |
| `h` | Help |
| `5` | Every key (from the help) |
| `7` | Every column |
| `s` | Settings |
| `q` | Quit |

## Notes

- It needs raw sockets; the package gives it that, no sudo.

Keys read from its own help screen.
