# lazyjournal

Logs: journald, files in /var/log, Docker and Podman containers.

Project: <https://github.com/Lifailon/lazyjournal>

## Start

- `lazyjournal`

## Keys

| Key | Action |
| --- | ------ |
| `Tab` `Shift Tab` | Next, previous window |
| `j` `k` | Move in a list or the log |
| `Left` `Right` | Other lists of the window |
| `Enter` | Load the log |
| `/` | Filter the log |
| `Ctrl e` `Ctrl a` | End, top of the log |
| `[` `]` | How many lines |
| `F2` | SSH hosts and contexts |
| `F1` | Every key |

Keys read from its own help screen.
