# serie

The commit graph of a repo, drawn with images of the branches.

Project: <https://github.com/lusingander/serie>

## Start

- `serie` in a repo

## Keys

| Key | Action |
| --- | ------ |
| `j` `k` | Move |
| `Enter` | Commit details |
| `Tab` | Branches and tags |
| `/` | Search |
| `n` `N` | Next, previous match |
| `Ctrl t` | What the search looks in |
| `g` `G` | Top, bottom |
| `Ctrl d` `Ctrl u` | Half a page |
| `?` `F1` | Every key |
| `q` | Quit |

Keys read from its own help screen.
