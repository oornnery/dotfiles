# Basalt

Obsidian vaults in the terminal: browse the notes of a vault and read them as
rendered Markdown.

Project: <https://basalt.page> (<https://github.com/erikjuhani/basalt>)

## Start

- `basalt`: pick a vault, then a note

## Keys

| Key | Action |
| --- | ------ |
| `/` | Search |
| `t` | Switch the theme |
| `Esc` | Close, or leave the search |
| `?` | Every key |

## Notes

- It finds the vaults Obsidian knows on Linux. Obsidian on Windows keeps its list
  on the Windows side, so a vault there may need its path the first time.

From its documentation.
