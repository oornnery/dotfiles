# eilmeldung

RSS and Atom feeds, read in the terminal.

Project: <https://github.com/christo-auer/eilmeldung>

## Start

- `eilmeldung`; the first time, pick Local
- Then `:importopml ~/.config/eilmeldung/feeds.opml` and `s`

## Keys

| Key | Action |
| --- | ------ |
| `s` | Sync |
| `j` `k` | Move |
| `h` `l` | Panels |
| `o` | Open in the browser |
| `r` `u` | Read, unread |
| `m` | Star |
| `1` `2` `3` | All, unread, starred |
| `/` | Search |
| `c f` | Add a feed |
| `?` | Every key |
| `q` | Quit |

## Notes

- The feeds are in `home/eilmeldung/.config/eilmeldung/feeds.opml`.

From its documentation.
