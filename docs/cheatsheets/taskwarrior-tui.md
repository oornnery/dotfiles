# taskwarrior-tui

Tasks of taskwarrior, in a list you edit with keys.

Project: <https://github.com/kdheepak/taskwarrior-tui>

## Start

- `taskwarrior-tui`
- From the shell: `task add Buy milk due:fri`, `task`, `task 3 done`

## Keys

| Key | Action |
| --- | ------ |
| `a` | Add |
| `d` | Done |
| `e` | Edit in the editor |
| `y` | Duplicate |
| `/` | Filter |
| `j` `k` | Move |
| `[` `]` | Views: tasks, projects, calendar |
| `?` | Help |
| `q` | Quit |

## Notes

- Data in `~/.local/share/task`, colors from the terminal (`home/task`).

Keys read from its own help screen.
