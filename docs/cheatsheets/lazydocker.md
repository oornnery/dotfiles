# lazydocker

Docker containers, images, volumes, logs and stats.

Project: <https://github.com/jesseduffield/lazydocker>

## Start

- `ld` or `lazydocker`

## Keys

| Key | Action |
| --- | ------ |
| `[` `]` | Tabs of the panel: logs, stats, config... |
| `Enter` | Focus the main panel |
| `r` | Restart |
| `s` | Stop |
| `d` | Remove |
| `E` | Shell in the container |
| `?` | Every key |
| `q` | Quit |
