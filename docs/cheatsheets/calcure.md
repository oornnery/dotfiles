# calcure

Calendar and tasks, side by side.

Project: <https://github.com/anufrievroman/calcure>

## Start

- `calcure`

## Keys

| Key | Action |
| --- | ------ |
| `Space` | Calendar, tasks |
| `a` `A` | Add (a recurring) event or task |
| `d` | Done |
| `x` | Delete |
| `r` | Rename |
| `n` `p` | Next, previous month |
| `v` `w` | Day, week view |
| `R` | Back to today |
| `?` | Help |
| `q` | Quit |

Keys read from its own help screen.
