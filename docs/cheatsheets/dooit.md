# dooit

Todo lists with workspaces, nested todos, due dates and urgency.

Project: <https://github.com/dooit-org/dooit>

## Start

- `dooit`

## Keys

| Key | Action |
| --- | ------ |
| `Tab` | Workspaces, todos |
| `a` `A` | Add, add inside |
| `i` | Edit the text |
| `d` | Due date |
| `c` | Done |
| `+` `-` | Urgency |
| `xx` | Remove |
| `z` | Expand |
| `/` | Search |
| `?` | Help |

Keys read from its own help screen.
