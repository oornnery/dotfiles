# btop

CPU, memory, disks, network and processes.

Project: <https://github.com/aristocratos/btop>

## Start

- `btop`

## Keys

| Key | Action |
| --- | ------ |
| `m` | Menu |
| `f` | Filter processes |
| `Up` `Down` | Select a process |
| `k` | Kill it |
| `t` | Tree view |
| `1`-`4` | Show or hide CPU, memory, network, processes |
| `q` | Quit |

## Notes

- Terminal colors: follows `dots theme`.
