# tabiew

Tables: CSV, TSV, Parquet, JSON, SQLite, Excel; filter, sort and query them with SQL.

Project: <https://github.com/shshemi/tabiew>

## Start

- `tw file.csv`
- `tw a.csv b.parquet`: one tab each

## Keys

| Key | Action |
| --- | ------ |
| `h` `j` `k` `l` | Move |
| `w` `b` | Next, previous column |
| `g` `G` | First, last row |
| `Enter` | The whole row |
| `q` | SQL query (the table is `df`) |
| `f` | Filter |
| `/` | Search |
| `t` | Tabs |
| `:` | Every command |
| `Q` | Quit |

From its documentation.
