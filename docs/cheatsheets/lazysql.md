# lazysql

Databases in panels, like lazygit: Postgres, MySQL, SQLite, SQL Server.

Project: <https://github.com/jorgerojas26/lazysql>

## Start

- `lazysql` (the alias turns off its usage counts)
- `lazysql postgres://user:pass@host/db`

## Keys

| Key | Action |
| --- | ------ |
| `n` | New connection |
| `Enter` `c` | Connect |
| `H` `L` | Tree, table |
| `Ctrl e` | SQL editor |
| `Ctrl r` | Run the query |
| `Ctrl s` | Save changes |
| `Ctrl p` | Search |
| `Backspace` | Back to the connections |
| `?` | Every key |

From its documentation.
