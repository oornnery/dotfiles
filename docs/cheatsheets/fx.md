# fx

JSON to browse: fold, search, follow paths, copy.

Project: <https://github.com/antonmedv/fx>

## Start

- `fx file.json`
- `curl -s url | fx`

## Keys

| Key | Action |
| --- | ------ |
| `j` `k` | Move |
| `l` `h` | Expand, collapse |
| `L` `H` | Expand, collapse everything inside |
| `e` `E` | Expand, collapse all |
| `1`-`9` | Collapse to that level |
| `/` | Search (regex) |
| `n` `N` | Next, previous match |
| `y` | Copy |
| `?` | Every key |
| `q` | Quit |

Keys read from its own help screen.
