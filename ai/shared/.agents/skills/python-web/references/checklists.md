# Python web checks

- Routes return intended status, headers, redirects, and content type.
- Forms preserve values and expose field/global errors safely.
- Authenticated and unauthorized paths are tested.
- Object-level authorization is enforced server-side.
- Transactions roll back on failure.
- Migrations upgrade from previous state and downgrade when policy requires.
- Templates are keyboard-usable, responsive, and escape untrusted content.
- Static assets/build/deployment assumptions are documented.
- Logs contain correlation/context without secrets or PII.
