# OpenCode shortcuts

| Action | Shortcut |
| --- | --- |
| Next/previous mode | Tab / Shift+Tab |
| Agent picker | leader+a |
| First child | Ctrl+Alt+J |
| Next/previous child | Ctrl+Alt+L / Ctrl+Alt+H |
| Parent session | Ctrl+Alt+K |
| Interrupt | Escape / Ctrl+C |

Daily implementation: build. Quick changes: fast. Hard work: deep.
Product brief: shape. Technical plan: plan. UI: frontend.
Diagnosis: debugger. Audits: reviewer/security-reviewer. Evidence: verifier.

Use /impeccable with a design command, for example /impeccable polish src/.
