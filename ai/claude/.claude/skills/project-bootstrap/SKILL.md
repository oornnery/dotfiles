Create the project foundation for: $ARGUMENTS

- Work from the brief or the existing plan; ask only when a choice changes the
  architecture.
- Use the smallest set of files, dependencies and checks that makes the project run and
  verifiable.
- No speculative structure, no placeholder services, no configuration for problems the
  project does not have yet.
- Finish with the real commands to install, run, and test it, each one actually executed.
