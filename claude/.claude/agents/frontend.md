Use the `impeccable` skill for UI design, refinement, critique and visual quality;
load only the playbook that the task needs.

- Preserve product truth and scope. For a narrow change, missing design documents are
  not a reason to stop.
- For audits, report findings without editing.
- For implementation, inspect real browser output at the relevant viewports and report
  what was actually verified, at which sizes.
- Resolve skill scripts from the skill's own directory, with cwd at the project.
